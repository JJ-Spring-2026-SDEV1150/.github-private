# NAIT-SDEV1150 **Spring 2026** Organization

## [Classroom Exercise Starters](https://github.com/NAIT-SDEV1150/Classroom-Exercises)
This repo contains all example starter packs for the associated lesson plans. Feel free to use them as they are, modify them, or create your own examples.

## [Workbook Template](https://github.com/NAIT-SDEV1150-Fall2025/workbook-template)
Use this template for you and your students to create a workbook that will be used for in-class and extra exercise work. The simplest way to use this repo is as a template for a GitHub classroom assignment, which will grant you access to all students' work and provide a means to give them feedback if necessary. A note for instructors, you may want to make your workbook public so that students can clone or copy any work they may have missed.
